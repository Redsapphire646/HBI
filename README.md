# Das HBI — Historical Bureau of Investigation

Ein Escape Game für die Sekundarstufe I (Zyklus 3), in dem die Schüler\*innen SQL lernen:

Im Storymodus finden die Schüler\*innen als Historiker\*in beim HBI Persönlichkeiten der Weltgeschichte, indem sie
Abfragen an eine Datenbank stellen.

Im "Wer bin ich?" (Übungsmodus) können die Schüler\*innen ihre SQL-Kenntnisse unter Beweis stellen, indem sie durch SQL-Abfragen 
das klassische Spiel "Wer bin ich?" gegen Kolleg\*innen spielen.

## Spielen

- **Online:** [Link zur Browserversion](https://redsapphire646.github.io/HBI/)
- **Offline:** [Link zum Download](https://github.com/Redsapphire646/HBI/archive/refs/heads/main.zip) oder oben rechts auf „Code“ → „Download ZIP“ klicken.
  Die ZIP-Datei entpacken und im Ordner auf `HBI.html` doppelklicken.
  Keine Installation und kein Internet nötig.

**Wichtig:** Die Datenbanken im Spiel sind selbst mit Hilfe von KI erstellt. Die Informationen zu den Persönlichkeiten der Geschichte
und zu den weiteren Datensätzen wurden bestmöglich überprüft, können aber Fehler enthalten.
